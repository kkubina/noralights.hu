# noralights.hu roadmap

## Phase 1 — Establish the brief

- [x] Create the project overview, roadmap, and repository instructions.
- [ ] Record the audience, primary visitor task, site language or languages, and launch pages in the project overview.
- [ ] Inventory available copy, images, and design references. If the site replaces existing pages, record their public URLs and which content should carry over.
- [ ] Identify who will maintain the content and where the site will run. Use those requirements to settle the stack.

Completion check: each launch page has a purpose, a proposed URL, and a known source for its content or a recorded gap.

## Phase 2 — Build the first page

- [x] Set up the chosen stack and document the local workflow.
- [x] Build the approved placeholder homepage with responsive photo crops, live typography, directional entrances, hover zoom, and a reduced-motion mode.

Completion check: build and preview the page locally, then inspect the layout on desktop and at 320px wide. Check navigation by keyboard and touch.

## Phase 3 — Complete launch content

- [ ] Build the remaining agreed routes and interactions. Add final copy, optimized media, and any required attribution.
- [ ] Add page titles, descriptions, canonical URLs, a sitemap, and a 404 page. Map any legacy redirects identified in Phase 1.

Completion check: open each launch URL directly in the built site, follow its links, and complete the primary visitor task.

## Phase 4 — Prepare for release

- [ ] Run the production build and relevant checks. Review content, responsive layouts, keyboard focus, and reduced-motion behavior.
- [ ] Document the hosting-specific release and rollback steps, required settings, and any outstanding launch issues.

Completion check: the owner can reproduce the build and identify the files and settings needed for release.
