# Dependencies and media

The build uses [Astro](https://github.com/withastro/astro) and its check tool (MIT), and [TypeScript](https://github.com/microsoft/TypeScript) (Apache-2.0). The lockfile records dependency versions and license identifiers. Installed packages include their license notices.

The homepage uses the owner-supplied Noralights session photography and footage, including a guitar composite made from the owner’s instrument reference. Source frames are listed in [the project overview](docs/README.md). All typography uses fonts installed on the visitor’s device.
